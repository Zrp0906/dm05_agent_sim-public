# 02｜启动推理服务

[上一篇｜准备并打包](../p01_prepare/01_准备并打包.md) · [下一篇｜启动仿真](../p03_agent/03_启动仿真.md)

OpenDM 从镜像内的 `/checkpoint` 加载模型，在 `7891` 端口提供 `POST /v1/infer`。Windows 的 WSL Ubuntu 已验证多核 CPU 推理。本轮选用 Tailscale 接入 Mac，完成仿真联调后再迁移到 GPU 主机。

## 连接方式

| 方式 | Mac 上 `low_level:` 下的 `server_url:` | 使用条件 |
| --- | --- | --- |
| **Tailscale（当前采用）** | `http://100.x.y.z:7891/v1/infer` | 两台电脑加入同一个 Tailscale 私网。Windows 用 Serve 转发本机端口。 |
| 同一局域网直连 | `http://WINDOWS_LAN_IP:7891/v1/infer` | Docker 用 `-p 7891:7891` 发布端口，Windows 防火墙允许 Mac 访问。 |
| 已有 VPN | `http://WINDOWS_VPN_IP:7891/v1/infer` | 两台电脑通过 VPN 可以互访，服务端口对 VPN 开放。 |
| SSH 隧道 | `http://127.0.0.1:17891/v1/infer` | Mac 能连到 Windows 的 SSH，服务端与登录密钥允许端口转发。Docker 将 `7891` 发布到 Windows 本机。 |
| 公网入口 | `https://YOUR_DOMAIN/v1/infer` | 需要可入站的公网地址和转发配置，以及提供 HTTPS 和身份认证的入口。普通家庭宽带若用了运营商级 NAT（CGNAT），仅配置家里路由器通常无法入站。 |

公网入口应完成身份认证，再转发到本机 `7891`。当前 Agent 未提供令牌配置，如需使用令牌，要先为客户端添加支持。 [路由器端口转发条件](https://www.tp-link.com/us/support/faq/785/)

使用 SSH 隧道时，在 Mac 终端运行以下命令，将 `WINDOWS_USER` 和 `WINDOWS_SSH_HOST` 换成实际用户名和 Mac 能连到的 SSH 地址，并保持该窗口运行。

```bash
ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:17891:127.0.0.1:7891 WINDOWS_USER@WINDOWS_SSH_HOST
```

## Tailscale

1. 在 Windows 系统和 Mac 安装 Tailscale，用同一个账号登录。在 Windows PowerShell 运行 `tailscale ip -4`，记下 Windows 的 `100.x.y.z` 地址。 [Windows 下载](https://tailscale.com/download/windows) · [Mac 下载](https://tailscale.com/download/mac)
2. 打开 Docker Desktop。在 Windows 的 WSL Ubuntu 使用已有的 `opendm-dm05:with-weights` 镜像启动服务。若旧容器还在运行，先在原终端按 `Ctrl+C`。下方端口映射只绑定 Windows 本机，供 Tailscale Serve 转发。 [Docker Desktop 端口映射](https://docs.docker.com/desktop/features/networking/#how-exposed-ports-work)

   ```bash
   docker run --rm -it --name dm05-cpu --pull=never \
     -e CUDA_VISIBLE_DEVICES=-1 \
     -p 127.0.0.1:7891:7891 --workdir /opt/opendm \
     opendm-dm05:with-weights \
     /opt/conda/bin/conda run --no-capture-output -n opendm \
     env -u OMP_NUM_THREADS -u MKL_NUM_THREADS \
     bash script/dm05_launcher.sh --exp opendm/exp/dm05_exp.py \
     --task inference \
     --model-config.model-name-or-path /checkpoint \
     --model-config.vision-attn-implementation sdpa \
     --model-config.action-attn-implementation eager \
     --model-config.no-liger-kernel \
     --inference-config.backend default \
     --inference-config.diffusion-steps 1
   ```

3. 保持 WSL 的服务窗口运行。在 Windows 管理员 PowerShell 运行第一条命令，看到 `{"status":"ok"}` 后开启转发。 [Tailscale TCP 转发](https://tailscale.com/docs/reference/tailscale-cli/serve#use-a-tcp-forwarder)

   ```powershell
   curl.exe -fsS --max-time 5 http://127.0.0.1:7891/health
   tailscale serve --bg --tcp=7891 tcp://127.0.0.1:7891
   tailscale serve status
   ```

4. [在 Mac 检查连通性并配置 Agent](../p03_agent/03_启动仿真.md#连接推理服务)。

## 迁移到 GPU 主机

将项目目录和镜像归档带到已配置 Docker GPU 支持且显存足够的 Ubuntu 主机。把工作流配置的 `image_archive` 指向外盘或本地归档，在项目根目录运行以下命令。自定义路径时，导入入口用 `--config configs/deployment.local.json`。 [OpenDM 硬件要求](https://github.com/dexmal/opendm#requirements)

```bash
python3 dm05_workflow/p02_inference/02_01_import_image.py
python3 dm05_workflow/p02_inference/02_02_start_inference.py
```

保持推理服务运行，按所用连接方式更新 Mac 的 Agent YAML 中 `low_level:` 下的 `server_url:`，再检查 `/health`。 [GPU 启动实现](_impl/p02_inference.py) · [OpenDM 推理说明](https://github.com/dexmal/opendm/blob/03f799120d425ead51d9482bb1da950b6dabade9/docs/zh/dm05_inference.md#dm05-基础预训练模型)
