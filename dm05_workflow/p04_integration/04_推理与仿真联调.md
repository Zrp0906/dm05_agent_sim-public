# 04｜验证推理与仿真联调

[上一篇｜启动仿真](../p03_agent/03_启动仿真.md) · [全部阶段](../../README.md)

用 MuJoCo 生成三路画面和 14 维状态，向已运行的 OpenDM 请求一次推理。收到动作后，将首个动作提交给仿真。

执行本阶段需要与第 03 步相同的授权组件。[阶段 03 前提](../p03_agent/03_启动仿真.md#使用说明与前提)

## 使用说明与前提

保持推理主机上的 OpenDM 服务运行。在 Mac 激活第 03 步使用的 Python 3.11 环境，并通过 `/health` 确认服务可达。通过 Tailscale 连接时，在 Agent YAML 中填写推理主机的 Tailscale IP。CPU 推理可将 `timeout` 设为 `900` 秒。[连接检查和 Agent 配置](../p03_agent/03_启动仿真.md#连接推理服务)

在 Mac 的项目根目录运行以下命令。指令默认读取 YAML 中 `orchestrator:` 下的 `fixed_prompt:`，也可用 `--task` 指定。

```bash
python dm05_workflow/p04_integration/04_01_check_integration.py
```

## 输入和输出

| 输入 | 输出 |
| --- | --- |
| 推理服务地址、三路仿真图像、14 维状态和任务文本 | `outputs/integration.json` 记录相机数、状态维度、返回的动作形状和首个动作提交结果 |

联调记录确认从观察到提交动作的链路。任务效果可在第 03 步的网页里观察。[联调实现](_impl/p04_integration.py)
