# 01｜准备并打包 OpenDM

[上一篇｜运行路线](../p00_pipeline/00_从零开始与运行路线.md) · [下一篇｜启动推理服务](../p02_inference/02_启动推理服务.md)

在 Windows 的 WSL Ubuntu 中准备程序、Python 环境和权重，导出可迁移的 Docker 归档。

## 使用说明与前提

在 Windows 管理员 PowerShell 安装 WSL Ubuntu。按提示重启后，打开 Ubuntu 并创建 Linux 用户。 [WSL 安装指南](https://learn.microsoft.com/windows/wsl/install)

```powershell
wsl --install -d Ubuntu-22.04
```

安装 Docker Desktop 并启用 WSL 2 后端。在 **Settings → Resources → WSL Integration** 中启用 **Ubuntu-22.04**。 [Docker Desktop 安装](https://docs.docker.com/desktop/setup/install/windows-install/) · [WSL 集成](https://docs.docker.com/desktop/features/wsl/#enable-docker-in-wsl-2-distributions)

把项目目录放到 Windows 可访问的位置。在 WSL Ubuntu 中进入项目根目录，依次运行两个入口。已有程序镜像和已校验权重时，直接运行第二条。

```bash
python3 dm05_workflow/p01_prepare/01_01_prepare_opendm.py
python3 dm05_workflow/p01_prepare/01_02_export_image.py
```

### 使用外置硬盘

复制标准配置为 `configs/deployment.local.json`。在 Mac 上把 `prepare_dir` 设为外盘上的路径，例如 `/Volumes/YOUR_DRIVE/opendm-prepared`，然后运行以下命令。

```bash
python3 dm05_workflow/p01_prepare/01_01_prepare_opendm.py \
  --config configs/deployment.local.json --download-weights
```

把外盘插到 Windows 后，在 WSL Ubuntu 中使用它的挂载路径。例如 Windows 盘符是 `E:` 时，可用 `sudo mkdir -p /mnt/e` 和 `sudo mount -t drvfs E: /mnt/e` 挂载。将 Windows 侧配置的 `prepare_dir` 和 `image_archive` 分别设为 `/mnt/e/opendm-prepared` 和 `/mnt/e/opendm-dm05-with-weights.tar`，再用 `01_02_export_image.py --config configs/deployment.local.json` 导出。 [WSL 磁盘挂载](https://learn.microsoft.com/windows/wsl/wsl2-mount-disk)

## 输入和输出

| 入口 | 输入 | 输出 |
| --- | --- | --- |
| `01_01` | 官方基础镜像、固定版本的 OpenDM 源码和模型 | `opendm-dm05:prepared`、`prepare_dir/checkpoints/DM05` |
| `01_02` | 程序镜像及已校验的权重目录 | `opendm-dm05:with-weights`、`image_archive` |

打包时把权重复制到镜像内的 `/checkpoint`。导出的归档包含运行模型所需的程序、环境和权重。 [准备与导出实现](_impl/p01_prepare.py)
