# 03｜在 Mac 启动 Agent 仿真

[上一篇｜启动推理服务](../p02_inference/02_启动推理服务.md) · [下一篇｜联调](../p04_integration/04_推理与仿真联调.md)

Mac 运行网页和 MuJoCo 双臂仿真。Agent 把任务、三路相机图像和 14 维状态发给 OpenDM，收到动作后交给仿真执行。

执行本阶段前，需要取得授权提供的 Agent 源码、配置和仿真资产。[Agent 目录说明](../../agent/README.md) · [第三方资产目录说明](../../third_party/README.md)

## 使用说明与前提

在 Mac 上激活装有 CPython 3.11 的 Conda 环境，并用 `python -m pip install -r requirements.txt` 安装项目依赖。如果还没有 `agent/config/opendm.local.yaml`，在项目根目录复制 Agent 配置。

```bash
cp -n agent/config/direct_opendm_config.example.yaml agent/config/opendm.local.yaml
```

打开 `agent/config/opendm.local.yaml`，确认 `robot.type` 设置为 `mujoco`。

```yaml
robot:
  type: mujoco
```

## 连接推理服务

本轮联调选用 Tailscale。先完成 Windows 侧的服务启动和端口转发，然后在 Mac 终端运行下面的命令。把 `100.x.y.z` 换成 Windows 上 `tailscale ip -4` 查到的地址。 [Tailscale 设置](../p02_inference/02_启动推理服务.md#tailscale) · [其他连接方式](../p02_inference/02_启动推理服务.md#连接方式)

```bash
curl --noproxy '*' -fsS --max-time 10 http://100.x.y.z:7891/health
```

返回 `{"status":"ok"}` 后，在 `agent/config/opendm.local.yaml` 中找到已有的 `low_level:`，只修改它下面的 `server_url:` 和 `timeout:` 两行。把示例地址换成 Windows 的 Tailscale IP。CPU 推理使用 900 秒的请求等待时间。

```yaml
low_level:
  server_url: "http://100.x.y.z:7891/v1/infer"
  timeout: 900
```

## 运行

推理服务启动后，在已激活的 Python 3.11 环境中，从 Mac 的项目根目录运行以下命令。

```bash
python dm05_workflow/p00_pipeline/00_02_run_pipeline.py --from-stage 3
```

总入口先检查 CPython 3.11、MuJoCo 和 Agent YAML，再启动仿真和网页。使用其他 YAML 时，追加 `--agent-config` 和文件路径。

打开 [Agent 网页](http://127.0.0.1:8022/)，确认正面、左腕和右腕画面都在刷新。输入任务并点击 **Go**。用 **Stop** 停止，用 **Reset** 复位。

使用固定任务时，在 YAML 的 `orchestrator:` 下填写 `fixed_prompt:`，并在工作流 JSON 中把 `fixed_task` 设为 `true`。可以把标准 JSON 复制到 `configs/deployment.local.json`，然后向总入口传入 `--config configs/deployment.local.json`。

## 输入和输出

| 输入 | 输出 |
| --- | --- |
| Agent YAML、任务、推理地址 | Agent 网页、三路相机画面和双臂动作 |

MuJoCo 模式使用关节角和夹爪开度。默认使用双臂示例工位，可在 `robot:` 下用 `physics_scene:` 指定兼容场景。在 Mac 登录后的桌面终端运行，以便使用 OpenGL 渲染相机。[Agent 启动实现](_impl/p03_launch.py)

## 其他配置

| 功能 | 配置 |
| --- | --- |
| 自动编排 | 在 `orchestrator:` 下写 `mode: auto`，在 `high_level:` 下写 `type: vlm` 并填写高层模型设置，在顶层填写 `task:`。 |
| 交互标注与完成判断 | 在 `orchestrator:` 下写 `mode: interactive`，在 `high_level:` 下写 `type: vlm_bbox` 并填写高层模型设置。同一处的 `verify_vlm:` 用于设置复核模型。 |
| 语音 | 交互模式下用 `voice_config` 指定语音配置。令牌默认从 `VOLCENGINE_ASR_ACCESS_TOKEN` 读取。 |
| MaaS 或 Realtime | 用 `--agent-config` 传入对应的仿真 YAML。Realtime 的 `infer_url:` 位于 `low_level:` 下面的 `client:` 内。 |

DOS-W1 真机的环境与机械臂服务单独配置。 [真机启动步骤](../../docs/dos_w1_setup_zh.md) · [编排模式与直控接口](../../docs/direct_low_level_usage_zh.md)
